# Privacy Policy

**Effective date:** 2026-10-02

This privacy policy applies to the personal Google Calendar integration ("the application") that Eelco van Bommel uses together with his self-hosted Home Assistant installation.

## What this application does

The application connects Home Assistant to a personal Google account so that calendar events can be shown on a home dashboard and used in personal home automations.

## What data is accessed

- Google account identity (name and e-mail address), to establish the connection.
- Read-only access to the calendars selected in Home Assistant.

## How the data is used

Calendar data is used only to display events and to trigger personal home automations. The data is processed locally on the user's own Home Assistant instance.

## Data sharing

No data is shared, sold, or transferred to any third party. The application is for personal use only.

## Data storage

Authentication tokens and calendar data are stored locally on the user's own Home Assistant instance. No data is retained beyond what Home Assistant itself stores locally.
